### 1. Enterprise Multi-Agent Knowledge & Research Assistant
- **Focus**: Agentic AI & LLMOps (`/projects/research-assistant`)
- **Problem**: Traditional naive RAG hallucinates when answering complex questions requiring cross-document synthesis, citation checks, and multi-step reasoning.
- **Architecture**: A cyclical LangGraph state machine consisting of a **Planner**, a **Hybrid Retriever** (Qdrant vector search + BM25 keyword search), and a **Fact-Checker** with structured JSON fallback.
- **Target Benchmarks**: Target 34% lower context hallucination; regression-evaluated on faithfulness, relevancy, and recall via Ragas/DeepEval.

### 2. High-Throughput Asynchronous AI Gateway & Task Engine
- **Focus**: Distributed Backend Systems (`/projects/ai-gateway`)
- **Problem**: Direct synchronous LLM invocations block worker threads, lack rate limiting, cause request timeouts, and risk provider lock-in.
- **Architecture**: Asynchronous request processing via FastAPI, Celery, and Redis queues. Integrates token-bucket rate limiting, semantic LRU cache deduplication, and LiteLLM multi-provider fallback (OpenAI, Anthropic, Gemini, Groq) with audit logging to PostgreSQL.
- **Target Benchmarks**: Target 250+ concurrent requests, sub-50ms queue latency, and >80% test coverage.

### 3. Production MLOps Anomaly Detection & Deployment System
- **Focus**: MLOps & Telemetry (`/projects/anomaly-detection`)
- **Problem**: Machine learning models in production silently degrade due to data and concept drift without versioned delivery and continuous monitoring.
- **Architecture**: Versioned tabular anomaly detection (XGBoost / Isolation Forest) tracked with MLflow and DVC. Packaged in Docker containers deployed to Kubernetes with Prometheus metrics, Grafana dashboards, and automated telemetry-triggered rollbacks.
- **Target Benchmarks**: Automated drift visibility and zero-downtime rolling updates with instant rollback triggers.

### 4. Multimodal Defect & Threat Inspection System
- **Focus**: Computer Vision & Edge AI (`/projects/defect-inspection`)
- **Problem**: High-speed industrial inspection requires combining raw image streams with operational sensor metadata in real time.
- **Architecture**: Lightweight YOLOv8 and PyTorch vision models exported to ONNX Runtime for optimized inference. Streams frames via FastAPI with PostgreSQL logging of detected defect anomalies and metadata.
- **Target Benchmarks**: Target 42 FPS edge inference rate; 94.2% mean Average Precision (mAP) across 5 defect categories.

### 5. Self-Healing BI & SQL Analytics Agent
- **Focus**: Applied AI & Analytics (`/projects/sql-bi-agent`)
- **Problem**: Text-to-SQL generators frequently fail on relational schema joins and can inject dangerous write operations into production data warehouses.
- **Architecture**: A LangGraph agent with read-only database connections that inspects schemas, generates validated SQL, runs dry-run queries, and automatically corrects syntax/runtime errors through up to 3 self-healing retry loops. Formats outputs with Pandas and Plotly charts for human review.
- **Target Benchmarks**: Target self-correction within 3 retries; 100% read-only execution safety.

## Interactive Components & Engineering Features

This website is a showcase of advanced frontend engineering, WebGL graphics, and Edge AI integrations. Below is a comprehensive breakdown of the bespoke components:

### 1. Murmuration Wordmark Hero Canvas (`murmuration-wordmark.tsx`)
- **Concept**: A flocking simulation of birds (Craig Reynolds' Boids algorithm) where the flock spontaneously congregates to form the typographic letters **"ALHAN"**.
- **Physics Engine**: Calculates separation, alignment, cohesion, spring forces toward letter points, and curl noise turbulence.
- **Predator Interaction**: Pointer movements simulate a predator hawk overhead, causing birds to violently scatter and organically reorganize.
- **Theme Synchronization**: Canvas dynamically samples CSS custom property tokens (`var(--foreground)`, `var(--primary)`) and handles window resizing with device-pixel-ratio scaling.

### 2. Interactive 3D Silver Robot (`robot-hero.tsx`)
- **Concept**: A 3D silver cybernetic companion mounted above the hero section.
- **Graphics Pipeline**: Built using Three.js and `@react-three/fiber`. Features procedural heart curve geometry, rounded metallic robot skull, glossy visor, floating antennae joints, soft contact shadows, and an HDR room lighting environment.
- **Interaction**: Follows pointer/cursor movements with dampened 3D rotation, gentle idle floating bobbing, and automatic viewport-boundary clamping. Supports `prefers-reduced-motion`.

### 3. The Ask Orb (`morph-orb.tsx` & `ask-orb.functions.ts`)
- **Concept**: An interactive morphing AI assistant docked directly beneath the 3D robot.
- **Visual State Machine**: Transitions through 9 distinct geometric states:
  $$\text{idle} \longrightarrow \text{launch} \longrightarrow \text{assemble} \longrightarrow \text{think} \longrightarrow \text{resolve} \longrightarrow \text{condense} \longrightarrow \text{unfold} \longrightarrow \text{answered} \longrightarrow \text{reset}$$
- **AI Intelligence**: Connected directly to an edge server function (`askOrb`) that queries Groq (`llama-3.3-70b-versatile`) with Google Gemini (`gemini-2.5-flash`) as backup.
- **Guardrails**: Prompt-engineered with strict grounding on Alhan's verified resume facts; politely rejects questions unrelated to Alhan's engineering background.

### 4. Procedural 3D Agentic Factory Machine (`agentic-factory-3d.tsx`)
- **Concept**: An interactive 3D WebGL machine representing the five stages of modern AI engineering:
  $$\text{Data} \longrightarrow \text{Build} \longrightarrow \text{Validate} \longrightarrow \text{Observe} \longrightarrow \text{Deploy}$$
- **Procedural Three.js**: 100% procedural WebGL code — no external 3D models (`.gltf`/`.obj`) or raster texture images.
- **Interaction Modes**:
  - `Assembled`: Full machine operational view.
  - `Cutaway`: Transparent chassis exposing inner gears and packet carriers.
  - `Stations`: Focus and inspect each station individually.
  - `One Order`: Trace a single data packet's voyage across the assembly line.
- **Camera Controls**: 5 cinematic camera rigs (`Overview`, `Side`, `Top`, `Station`, `Flight`) with smooth orbital controls and station hover tooltips.

### 5. AI Role Matcher (`RoleMatch.tsx` & `role-match.functions.ts`)
- **Concept**: An interactive recruiter tool that analyzes the visitor's hiring needs against Alhan's catalog.
- **Execution**: The visitor picks one of four roles. The server function queries the LLM using **structured JSON output mode** constrained to existing project slugs and verified skills, guaranteeing zero hallucinations.
- **Result Card**: Displays a customized 2-sentence rationale, top 2–3 matching projects, and the most relevant technical skills.

### 6. Orbit Spotlight Gallery (`orbit-spotlight-gallery.tsx`)
- **Concept**: A circular orbital gallery showcasing all 5 in-progress systems.
- **Features**: Nodes orbit smoothly in 3D perspective with active spotlight elevation. Selecting an item updates the adjacent project card, tech tags, target metrics, and links without scrolling or layout shifting.

### 7. Quantified Signal & Draggable Bento Grid (`QuantifiedSignal.tsx` & `draggable-widget-grid.tsx`)

## AI Architecture & Edge Integrations

The AI integrations are engineered without third-party proxy dependencies:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        AI PIPELINE ARCHITECTURE                        │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   Client Request (Ask Orb or Role Match)                               │
│              │                                                         │
│              ▼                                                         │
│   TanStack Start Server Function (createServerFn)                      │
│              │                                                         │
│              ├──► 1. Primary: Groq REST API                            │
│              │    (llama-3.3-70b-versatile, <300ms ultra-low latency)  │
│              │                                                         │
│              └──► 2. Fallback: Google Gemini REST API                  │
│                   (gemini-2.5-flash / gemini-3.8-flash)                │
│                                                                        │
│              │                                                         │
│              ▼                                                         │
│   Runtime Schema Validation & Guardrails                               │
│   - Structured JSON parsing                                            │
│   - Project slug & skill whitelist verification                        │
│   - Numerical claims forced to "target" labels                         │
│              │                                                         │
│              ▼                                                         │
│   Hydrated Result returned to Client Component                         │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

- **Groq Primary**: Fast responses for conversational Q&A and matching.
- **Gemini Fallback**: Seamless fallback ensures high uptime if Groq rate limits or fails.
- **REST Fetch over SDKs**: Direct REST requests via standard `fetch` prevent edge runtime incompatibilities.

## Getting Started & Local Setup

### Prerequisites

- **[Bun](https://bun.sh/)** v1.2+ (Recommended) or **Node.js** v20+ with `npm`
- Git

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/alhaannn/alhan-portfolio.git
cd alhan-portfolio
bun install
```

### Environment Variables

Copy the example environment configuration:

```bash
cp .env.example .env
```

Open `.env` and add your API keys:

```env
# Optional for basic browsing, required for AI Ask Orb and Role Matcher:
GROQ_API_KEY=your_groq_api_key_here
GOOGLE_API_KEY=your_google_gemini_api_key_here
```

> **Note**: Free API keys are available at [console.groq.com](https://console.groq.com/) and [aistudio.google.com](https://aistudio.google.com/).

### Development Server

Start the local Vite development server:

```bash

bun run build
```

```bash
bun run lint
```

#### Cloudflare Workers Deployment
The build output is optimized for Cloudflare Workers via `@cloudflare/vite-plugin`. Deploy using Wrangler:

```bash
bunx wrangler deploy
```

#### Vercel Deployment
Compatible out of the box with Vercel's edge/node runtime. Connect your GitHub repository and set `GROQ_API_KEY` and `GOOGLE_API_KEY` under **Project Settings > Environment Variables**.

## SEO & AI Discoverability

This portfolio implements cutting-edge discoverability for human visitors, search engine crawlers, and LLM web agents:

1. **Schema.org Structured Data**: Complete `Person` and `WebSite` JSON-LD schemas in `__root.tsx` covering alumni relationships, credentials, skills, and social handles.
2. **OpenGraph & Twitter Cards**: Dynamic page-specific title, description, and canonical 1200×630 share artwork for every route.
3. **Machine-Readable Documentation (`/llms.txt`)**: Real-time server-rendered text manifest conforming to the emerging `/llms.txt` standard, enabling AI assistants (ChatGPT, Claude, Perplexity) to digest Alhan's engineering background accurately.
4. **Automated Robots & Sitemap**: Dynamically generated XML sitemap (`/sitemap.xml`) and search directives (`/robots.txt`) ensuring rapid crawling of all projects and role pages.
